# Texto Privacy Policy

**Effective Date**: January 2026

---

## Introduction

Texto ("we" or "this application") values your privacy protection. This Privacy Policy explains how we collect, use, and protect your information when you use the Texto Markdown editor.

Please read this Privacy Policy carefully. By using this application, you agree to the terms of this policy.

---

## Information We Collect

### 1. Locally Stored Data

Texto is a local-first Markdown editor. All data is **stored only locally on your device**. We do not collect or transmit any of your personal information to remote servers.

We only store the following information locally to provide a better user experience:

| Data Type | Purpose | Storage Location |
|-----------|---------|------------------|
| App Settings | Theme, font, language, and other preferences | Local configuration file |
| Shortcut Configuration | Custom shortcuts | Local storage |
| Interface State | Sidebar width, collapsed state, etc. | Browser local storage |
| Recent Files List | Paths of recently opened documents | Browser local storage |
| Currently Open Folder | Restore last working directory | Browser local storage |

### 2. Document Content

- All Markdown documents you create and edit are **stored entirely locally on your device**
- We do not upload, access, or back up your document content
- You have full control over your documents

### 3. Information We Do Not Collect

Texto **does not** collect the following information:

- ❌ Personal identification information (name, email, phone, etc.)
- ❌ Usage analytics or statistics
- ❌ Crash reports (unless you actively provide feedback via email)
- ❌ Device information or location data
- ❌ Network activity data

---

## Data Usage

### Purpose of Locally Stored Data

The data we store is only used for:

1. **Remembering your preferences** - such as theme, font, and language selection
2. **Restoring work state** - such as last opened folder, window size
3. **Providing quick functions** - such as recent files list
4. **Personalized shortcuts** - saving your custom shortcut configurations

### Data Storage Technologies

- **Tauri Store**: Used for storing application configuration
- **LocalStorage**: Used for storing interface state and temporary data
- **File System**: Your documents are saved directly to your chosen location

---

## Data Security

### Local Security

- All data is stored locally on your device, protected by macOS sandbox mechanism
- The application cannot access unauthorized files or directories
- You can clear application data at any time through system settings

### Network Security

- Texto does not connect to any remote servers by default
- Network requests are only made when you actively insert web images
- No document content or personal data is transmitted

---

## Your Rights

As a user, you have the following rights:

### Access and Modification

- You can view and modify all configurations in the application settings at any time
- Your documents are entirely under your control and can be exported, deleted, or migrated at any time

### Data Deletion

- **Clear App Settings**: Click "Restore Default Settings" in "Settings" → "About"
- **Delete Recent Files History**: Select "Clear Recent Projects" in the "File" menu
- **Complete Uninstall**: Delete the application to clear all local data

### Data Migration

- Your Markdown files are in standard format and can be migrated to other editors at any time
- Configuration data is stored in JSON format and can be manually backed up
