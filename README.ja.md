# Texto テクニカルサポート

Texto - シンプルでエレガントな Markdown エディタ

---

## よくある質問

### ファイル操作

**Q: ファイルを開くには？**
A: ショートカット `Cmd + O` を使用するか、メニュー「ファイル」→「開く」をクリックします。`.md`、`.markdown`、`.mdown`、`.mkd` 形式に対応しています。

**Q: フォルダを開くには？**
A: ショートカット `Cmd + Shift + O` を使用するか、メニュー「ファイル」→「フォルダを開く」をクリックします。左側にディレクトリツリーが表示されます。

**Q: ファイルを保存するには？**
A: ショートカット `Cmd + S` で現在のファイルを保存します。設定で「自動保存」機能を有効にできます。

**Q: 新しいウィンドウを作成するには？**
A: ショートカット `Cmd + N` で新しいウィンドウを開きます。

**Q: 最近開いたファイルを確認するには？**
A: メニュー「ファイル」→「最近開いたプロジェクト」をクリックしてリストを確認します。「最近のプロジェクトをクリア」をクリックすると履歴を消去できます。

### 編集機能

**Q: 編集モードを切り替えるには？**
A: ショートカット `Cmd + /` で即時レンダリングと分割画面プレビューモードを切り替えます。

**Q: 操作を元に戻す/やり直すには？**
A: `Cmd + Z` で元に戻し、`Cmd + Shift + Z` でやり直します。

**Q: どのような書式ショートカットがサポートされていますか？**
A: エディタでサポートされている書式ショートカット：
- `Cmd + B`：太字（**テキスト**）
- `Cmd + I`：斜体（*テキスト*）
- `Cmd + 1~6`：見出しレベル 1~6（# ~ ######）

リンクの挿入はメニュー「書式」→「リンク」またはコマンドパレットから行えます。

### ディレクトリツリーとサイドバー

**Q: ディレクトリツリーの表示/非表示を切り替えるには？**
A: ショートカット `Cmd + T` を使用するか、メニュー「表示」→「ディレクトリツリーの切り替え」をクリックします。

**Q: ディレクトリツリーで新しいファイル/フォルダを作成するには？**
A: ディレクトリツリーのフォルダを右クリックし、「新規ファイル」または「新規フォルダ」を選択します。

**Q: ファイルの名前変更や削除を行うには？**
A: ディレクトリツリーのファイルを右クリックし、「名前変更」または「削除」を選択します。

### テーマと外観

**Q: ダーク/ライトモードを切り替えるには？**
A: 「設定」→「パーソナライズ」で、「外観」を「ライト」、「ダーク」、または「システムに従う」から選択します。

**Q: カラーテーマを変更するには？**
A: 「設定」→「パーソナライズ」→「カラーテーマ」で、「デフォルト」、「パステル」、または「レッド」テーマから選択できます。

**Q: どのようなコードエディタテーマがサポートされていますか？**
A: Atom One、Dracula、Eclipse、GitHub、Material、Sublime、VS Code、Xcode など、多数のテーマをサポートしています。設定でライトモードとダークモードのテーマを別々に設定できます。

**Q: エディタのフォントサイズを調整するには？**
A: 「設定」→「エディタ」で、「エディタフォントサイズ」スライダーをドラッグして調整します。

### 数式

**Q: 数式を書くには？**
A: LaTeX 構文を使用します：
- インライン数式：単一の `$` で囲みます。例：`$E=mc^2$`
- ブロック数式：二重の `$$` で囲むか、メニュー「段落」→「数式ブロック」を使用します

**Q: 数式でどのような機能がサポートされていますか？**
A: MathJax エンジンをベースに、完全な LaTeX 数学構文をサポートしています。分数、平方根、積分、行列、化学方程式などが含まれます。

### チャートとコード

**Q: Mermaid チャートを挿入するには？**
A: メニュー「段落」→「Mermaid チャート」をクリックします。フローチャート、シーケンス図、ガントチャート、クラス図などに対応しています。

**Q: コードブロックを挿入するには？**
A: メニュー「段落」→「コードブロック」をクリックします。JavaScript、TypeScript、Python、Rust、Go、Java、C/C++、HTML、CSS、SQL、YAML など、20 以上のプログラミング言語の構文強調をサポートしています。

**Q: コードブロックでどのような操作がサポートされていますか？**
A: コードのコピー、コードブロックの折りたたみ/展開に対応しています。設定でコードブロックの自動改行を設定できます。

### テーブル操作

**Q: テーブルを挿入するには？**
A: メニュー「段落」→「テーブル」をクリックし、行数と列数を選択して挿入します。

**Q: テーブルを編集するには？**
A: テーブルを選択した後、テーブルツールバーを使用して行/列の挿入、行/列の削除、セルの結合、配置などの操作を行います。

### タスクリスト

**Q: タスクリストを使用するには？**
A: メニュー「段落」→「タスクリスト」をクリックしてタスク項目を挿入します。チェックボックスをクリックして完了状態をマークします。

**Q: タスクリストは自動的に並べ替えられますか？**
A: はい、「設定」→「エディタ」で「タスクリスト自動並べ替え」を有効にできます。チェック後、完了したタスクはリストの下部に自動的に移動します。

### 画像処理

**Q: 画像を挿入するには？**
A: メニュー「段落」→「画像を挿入」を使用するか、エディタに画像をドラッグ＆ドロップします。画像の貼り付けにも対応しています。

**Q: 画像はどこに保存されますか？**
A: 「設定」→「画像保存」で設定できます：
- ドキュメントと同じディレクトリ（デフォルト）
- アプリケーションデータディレクトリ
- カスタムディレクトリ

**Q: 画像を集約して保存するには？**
A: ドキュメント名または日付（年/年月/年月日）で画像を集約して保存できます。

### 国際化

**Q: インターフェース言語を切り替えるには？**
A: 「設定」→「エディタ」→「言語」で、「簡体字中国語」または「English」を選択します。

### コマンドパレット

**Q: コマンドパレットを使用するには？**
A: ショートカット `Cmd + P` でコマンドパレットを開き、コマンドを素早く検索して実行できます。

**Q: アウトラインを検索するには？**
A: コマンドパレットで `#` を入力すると、ドキュメントのアウトライン見出しを検索できます。

### ショートカット設定

**Q: ショートカットをカスタマイズするには？**
A: 「設定」→「ショートカット」で、変更したいショートカットをクリックし、新しいキー組み合わせを押して Enter を押して確定します。

**Q: ショートカットをリセットするには？**
A: 「設定」→「ショートカット」で、「デフォルトにリセット」ボタンをクリックします。

### 外部ファイルの変更

**Q: ファイルが他の場所で変更された場合はどうすればよいですか？**
A: 「設定」→「エディタ」→「外部ファイル変更の処理」で、以下から選択できます：
- 無視（監視しない）
- 静かに更新
- ポップアップ通知

### ログとフィードバック

**Q: ログをエクスポートするには？**
A: メニュー「ヘルプ」→「ログをエクスポート」をクリックしてアプリケーションログをエクスポートし、問題の調査に使用します。

**Q: フィードバックを送信するには？**
A: メニュー「ヘルプ」→「フィードバック」をクリックして連絡先情報を取得します。
