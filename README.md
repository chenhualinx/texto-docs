# Texto 技术支持

Texto - 简洁优雅的 Markdown 编辑器

---

## 常见问题

### 文件操作

**Q: 如何打开文件？**
A: 使用快捷键 `Cmd + O` 或点击菜单「文件」→「打开」，支持 `.md`、`.markdown`、`.mdown`、`.mkd` 格式。

**Q: 如何打开文件夹？**
A: 使用快捷键 `Cmd + Shift + O` 或点击菜单「文件」→「打开文件夹」，左侧将显示目录树。

**Q: 如何保存文件？**
A: 使用快捷键 `Cmd + S` 保存当前文件。可在设置中开启「自动保存」功能。

**Q: 如何新建窗口？**
A: 使用快捷键 `Cmd + N` 打开新窗口。

**Q: 如何查看最近打开的文件？**
A: 点击菜单「文件」→「打开最近的项目」查看列表，点击「清除最近项目」可清空历史。

### 编辑功能

**Q: 如何切换编辑模式？**
A: 使用快捷键 `Cmd + /` 在即时渲染和分屏预览模式之间切换。

**Q: 如何撤销/重做操作？**
A: 使用 `Cmd + Z` 撤销，`Cmd + Shift + Z` 重做。

**Q: 支持哪些格式快捷键？**
A: 编辑器内支持的格式快捷键：
- `Cmd + B`：加粗（**文本**）
- `Cmd + I`：斜体（*文本*）
- `Cmd + 1~6`：标题 1~6 级（# ~ ######）

插入链接可通过菜单「格式」→「链接」或命令面板操作。

### 目录树与侧边栏

**Q: 如何显示/隐藏目录树？**
A: 使用快捷键 `Cmd + T` 或点击菜单「视图」→「切换目录树」。

**Q: 如何在目录树中新建文件/文件夹？**
A: 右键点击目录树中的文件夹，选择「新建文件」或「新建文件夹」。

**Q: 如何重命名或删除文件？**
A: 右键点击目录树中的文件，选择「重命名」或「删除」。

### 主题与外观

**Q: 如何切换深色/浅色模式？**
A: 在「设置」→「个性化」中，选择「外观」为「浅色」、「深色」或「跟随系统」。

**Q: 如何更换颜色主题？**
A: 在「设置」→「个性化」→「颜色主题」中，可选择「默认」、「粉彩」或「红色」主题。

**Q: 支持哪些代码编辑器主题？**
A: 支持 Atom One、Dracula、Eclipse、GitHub、Material、Sublime、VS Code、Xcode 等多种主题，可在设置中分别配置亮色和暗色模式的主题。

**Q: 如何调整编辑器字体大小？**
A: 在「设置」→「编辑器」中，拖动「编辑器字体大小」滑块调整。

### 数学公式

**Q: 如何编写数学公式？**
A: 使用 LaTeX 语法：
- 行内公式：使用单个 `$` 包裹，如 `$E=mc^2$`
- 块级公式：使用双 `$$` 包裹，或使用菜单「段落」→「公式块」

**Q: 数学公式支持哪些功能？**
A: 基于 MathJax 引擎，支持完整的 LaTeX 数学语法，包括分数、根号、积分、矩阵、化学方程式等。

### 图表与代码

**Q: 如何插入 Mermaid 图表？**
A: 点击菜单「段落」→「Mermaid 图表」，支持流程图、时序图、甘特图、类图等。

**Q: 如何插入代码块？**
A: 点击菜单「段落」→「代码块」，支持 20+ 种编程语言高亮，包括 JavaScript、TypeScript、Python、Rust、Go、Java、C/C++、HTML、CSS、SQL、YAML 等。

**Q: 代码块支持哪些操作？**
A: 支持复制代码、折叠/展开代码块，可在设置中配置代码块自动换行。

### 表格操作

**Q: 如何插入表格？**
A: 点击菜单「段落」→「表格」，选择行列数后插入。

**Q: 如何编辑表格？**
A: 选中表格后，使用表格工具栏进行插入行列、删除行列、合并单元格、对齐等操作。

### 任务列表

**Q: 如何使用任务列表？**
A: 点击菜单「段落」→「任务列表」插入任务项，点击复选框标记完成状态。

**Q: 任务列表可以自动排序吗？**
A: 可以，在「设置」→「编辑器」中开启「任务列表自动排序」，勾选后已完成的任务将自动移到列表底部。

### 图片处理

**Q: 如何插入图片？**
A: 使用菜单「段落」→「插入图片」或拖拽图片到编辑器。支持粘贴图片。

**Q: 图片存储在哪里？**
A: 可在「设置」→「图片存储」中配置：
- 文档同级目录（默认）
- 应用数据目录
- 自定义目录

**Q: 图片如何聚合存储？**
A: 支持按文档名称或按日期（年/年月/年月日）聚合存储图片。

### 国际化

**Q: 如何切换界面语言？**
A: 在「设置」→「编辑器」→「语言」中，选择「简体中文」或「English」。

### 命令面板

**Q: 如何使用命令面板？**
A: 使用快捷键 `Cmd + P` 打开命令面板，可快速搜索并执行命令。

**Q: 如何搜索大纲？**
A: 在命令面板中输入 `#` 可搜索文档大纲标题。

### 快捷键设置

**Q: 如何自定义快捷键？**
A: 在「设置」→「快捷键」中，点击要修改的快捷键，按下新的组合键后按回车确认。

**Q: 如何重置快捷键？**
A: 在「设置」→「快捷键」中，点击「重置为默认」按钮。

### 外部文件变更

**Q: 文件在其他地方被修改了怎么办？**
A: 在「设置」→「编辑器」→「外部文件修改处理」中，可选择：
- 忽略（不监听）
- 静默刷新
- 弹窗提示

### 日志与反馈

**Q: 如何导出日志？**
A: 点击菜单「帮助」→「导出日志」导出应用日志，用于问题排查。

**Q: 如何提交反馈？**
A: 点击菜单「帮助」→「反馈」获取联系方式。
