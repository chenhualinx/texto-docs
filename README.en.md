## FAQ

### File Operations

**Q: How to open a file?**
A: Use the shortcut `Cmd + O` or click the menu "File" → "Open". Supports `.md`, `.markdown`, `.mdown`, `.mkd` formats.

**Q: How to open a folder?**
A: Use the shortcut `Cmd + Shift + O` or click the menu "File" → "Open Folder". The directory tree will be displayed on the left.

**Q: How to save a file?**
A: Use the shortcut `Cmd + S` to save the current file. You can enable the "Auto Save" feature in settings.

**Q: How to create a new window?**
A: Use the shortcut `Cmd + N` to open a new window.

**Q: How to view recently opened files?**
A: Click the menu "File" → "Open Recent" to view the list. Click "Clear Recent Projects" to clear the history.

### Editing Features

**Q: How to switch editing modes?**
A: Use the shortcut `Cmd + /` to switch between instant rendering and split-screen preview modes.

**Q: How to undo/redo operations?**
A: Use `Cmd + Z` to undo and `Cmd + Shift + Z` to redo.

**Q: What formatting shortcuts are supported?**
A: The editor supports the following formatting shortcuts:
- `Cmd + B`: Bold (**text**)
- `Cmd + I`: Italic (*text*)
- `Cmd + 1~6`: Heading levels 1~6 (# ~ ######)

Insert links via the menu "Format" → "Link" or through the command palette.

### Directory Tree & Sidebar

**Q: How to show/hide the directory tree?**
A: Use the shortcut `Cmd + T` or click the menu "View" → "Toggle Directory Tree".

**Q: How to create new files/folders in the directory tree?**
A: Right-click on a folder in the directory tree and select "New File" or "New Folder".

**Q: How to rename or delete files?**
A: Right-click on a file in the directory tree and select "Rename" or "Delete".

### Themes & Appearance

**Q: How to switch between dark/light mode?**
A: In "Settings" → "Personalization", select "Appearance" as "Light", "Dark", or "Follow System".

**Q: How to change the color theme?**
A: In "Settings" → "Personalization" → "Color Theme", you can choose from "Default", "Pastel", or "Red" themes.

**Q: What code editor themes are supported?**
A: Supports Atom One, Dracula, Eclipse, GitHub, Material, Sublime, VS Code, Xcode, and many other themes. You can configure different themes for light and dark modes in settings.

**Q: How to adjust the editor font size?**
A: In "Settings" → "Editor", drag the "Editor Font Size" slider to adjust.

### Math Formulas

**Q: How to write math formulas?**
A: Use LaTeX syntax:
- Inline formula: Use single `$` wrapping, e.g., `$E=mc^2$`
- Block formula: Use double `$$` wrapping, or use the menu "Paragraph" → "Formula Block"

**Q: What features are supported for math formulas?**
A: Based on the MathJax engine, supports full LaTeX math syntax including fractions, square roots, integrals, matrices, chemical equations, etc.

### Charts & Code

**Q: How to insert Mermaid charts?**
A: Click the menu "Paragraph" → "Mermaid Chart". Supports flowcharts, sequence diagrams, Gantt charts, class diagrams, etc.

**Q: How to insert code blocks?**
A: Click the menu "Paragraph" → "Code Block". Supports 20+ programming languages highlighting, including JavaScript, TypeScript, Python, Rust, Go, Java, C/C++, HTML, CSS, SQL, YAML, etc.

**Q: What operations are supported for code blocks?**
A: Supports copying code, folding/expanding code blocks. You can configure code block word wrapping in settings.

### Table Operations

**Q: How to insert a table?**
A: Click the menu "Paragraph" → "Table", select the number of rows and columns to insert.

**Q: How to edit a table?**
A: After selecting a table, use the table toolbar to insert rows/columns, delete rows/columns, merge cells, align, and more.

### Task Lists

**Q: How to use task lists?**
A: Click the menu "Paragraph" → "Task List" to insert task items. Click the checkbox to mark completion status.

**Q: Can task lists be automatically sorted?**
A: Yes, enable "Task List Auto Sort" in "Settings" → "Editor". After checking, completed tasks will automatically move to the bottom of the list.

### Image Handling

**Q: How to insert images?**
A: Use the menu "Paragraph" → "Insert Image" or drag and drop images into the editor. Supports pasting images.

**Q: Where are images stored?**
A: You can configure this in "Settings" → "Image Storage":
- Same directory as document (default)
- Application data directory
- Custom directory

**Q: How to aggregate image storage?**
A: Supports aggregating image storage by document name or by date (year/year-month/year-month-day).

### Internationalization

**Q: How to switch the interface language?**
A: In "Settings" → "Editor" → "Language", select "Simplified Chinese" or "English".

### Command Palette

**Q: How to use the command palette?**
A: Use the shortcut `Cmd + P` to open the command palette for quick searching and executing commands.

**Q: How to search the outline?**
A: Enter `#` in the command palette to search for document outline headings.

### Shortcut Settings

**Q: How to customize shortcuts?**
A: In "Settings" → "Shortcuts", click the shortcut you want to modify, press the new key combination, and press Enter to confirm.

**Q: How to reset shortcuts?**
A: In "Settings" → "Shortcuts", click the "Reset to Default" button.

### External File Changes

**Q: What if a file is modified elsewhere?**
A: In "Settings" → "Editor" → "External File Modification Handling", you can choose:
- Ignore (do not monitor)
- Silent refresh
- Popup notification

### Logs & Feedback

**Q: How to export logs?**
A: Click the menu "Help" → "Export Logs" to export application logs for troubleshooting.

**Q: How to submit feedback?**
A: Click the menu "Help" → "Feedback" to get contact information.
